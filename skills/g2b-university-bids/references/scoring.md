# 컨설팅 적합도 점수 기준

공고명 키워드로 1차 선별한다. 사전을 고칠 때는 `scripts/search_bids.py`의 `HIGH`, `HIGH_REGEX`, `MID`, `SI`, `SI_STRONG`, `EXCLUDE`, `EXCLUDE_REGEX`, `NON_UNIV` 목록도 같이 고친다.

## 매칭 규칙

- 공고명의 띄어쓰기를 지운 뒤 비교한다. 예를 들어 "방안 수립"과 "방안수립"은 같은 것으로 본다.
- 영문 약어(AI, AX, DX, ISP, ISMP, BPR, RISE)는 **단어 단위로만** 매칭한다. KAIST 안의 'AI'는 매칭하지 않는다.
- '전략'은 '전략산업'(인력양성 사업명)일 때 매칭하지 않는다.
- '개편'은 앞에 홈페이지·누리집·사이트·웹이 붙으면 매칭하지 않는다.
- '운영체계'는 제외어 '프로그램운영'·'운영지원' 판정에서 빼고 본다.
- 제외어 '합성'은 '통합성과'(통합 성과관리) 안에서는 매칭하지 않는다.

## 점수 계산

| 요소 | 점수 |
|---|---|
| 핵심 키워드 1개당 | +3 |
| 일반 키워드 1개당 | +1 |
| SI형 키워드 1개당 (핵심 키워드가 하나도 없을 때만) | −2 |
| 강한 SI형 키워드 1개당 (`시스템구축`·`구축사업`, 핵심 키워드가 있어도) | −2 |
| 제외 키워드 1개당 | −5 |
| 예산 3억 이상 (핵심 키워드가 있을 때만) | +2 |
| 예산 1억 이상 (핵심 키워드가 있을 때만) | +1 |

## 등급

| 등급 | 점수 | 의미 |
|---|---|---|
| A | 5 이상 | 이번 주 바로 검토 |
| B | 2~4 | 관심 공고. 제안요청서 확인 후 판단 |
| C | 1 이하 | 비컨설팅 (시설·구매·행사·운영대행·SI 등). CSV에만 남김 |

- **SI형(−2)**: 시스템구축, 구축용역, 고도화, 솔루션, 개발용역, 구축사업

- **제외(−5)**

  - 구매·지원: 급식, 식당, 구매, 임차, 렌탈, 인쇄, 운송, 버스, 운행, 보험, 번역, 숙식, 방역, 소독, 폐기물

  - 병원·연구지원: 세탁, 린넨, 위탁검사, 검진, 콜센터, 채용, 회계감사, 결산, 정산, 특허, 합성, 시험법, 부품, 조립, 프로토타입
  - 제작: 촬영, 영상, 콘텐츠, 컨텐츠

## 대상 기관

- 수요기관명 검색어: `대학`, `과학기술원`
- 제외 기관(`NON_UNIV`): 한국해양과학기술원 및 부설기관('과학기술원' 검색에 잡히지만 대학이 아님), 대학경기대회 조직위원회(재단법인, '대학' 검색에 잡힘)

## 중복 제거

1. 같은 공고번호는 최신 차수만 남긴다 (정정공고).
2. 번호가 달라도 공고명과 수요기관이 같으면 가장 최근 공고만 남긴다 (재공고).

## AX·DX 공고 분류 (등급과 별도)

A/B/C 등급은 컨설팅 수주 가능성을 본다. AX·DX 섹션은 그와 상관없이 **대학의 AX 투자 동향**을 본다. 그래서 SI 감점을 적용하지 않는다. 다만 시설·행사·운영대행 같은 제외어에 걸리면 넣지 않는다.

- **AX 판별어**: AX, AI, DX, 인공지능, 디지털전환, 생성형, LLM, 에이전트, Agent, 에듀테크, LXP, LMS, 빅데이터, 데이터레이크, Data Lake, 디지털트윈, 메타버스, 클라우드, 지능형, 스마트캠퍼스, 스마트병원, 챗봇, AID
- **유형 분류** (위에서부터 먼저 맞는 것 하나)

| 유형 | 판별어 | 의미 |
|---|---|---|
| 전략·진단 | 전략, 진단, 컨설팅, 로드맵, ISP, ISMP, 체계, 방안수립, 마스터플랜, 기본계획, 타당성 | 직접 수주 후보 |
| 인프라·데이터 (강) | 주권AI, 데이터센터, GPU, 클라우드, 데이터레이크 | 대규모 AX 투자 신호 |
| 교육·학사 플랫폼 | LXP, LMS, 학습, 학사, 학생, 튜터, 에듀테크, 교육과정, 강좌, Advisor, 면접, 원격교육, 교과 | 교육 혁신형 AX |
| 인프라·데이터 | 데이터, 인프라, 네트워크, 디지털트윈 | 데이터 기반 구축 |
| 행정·업무 시스템 | 행정, 업무, 포털, 그룹웨어, 시스템 | 행정 AX |
| 기타 | 위에 해당 없음 | 연구·창업 프로그램 등 |
